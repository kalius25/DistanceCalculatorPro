# DistanceCalculatorPro — Sprint 1A

## Run

From the project root:

```bash
python -m pip install -r requirements.txt
python -m app.presentation.app
```

## Included

- PySide6 application bootstrap
- MainWindow
- Menu bar
- Toolbar
- Left navigation
- QStackedWidget pages
- Status bar
- Light and dark QSS themes
- Approved presentation coding convention

## Not Included Yet

- Excel integration
- Controllers and services
- Route calculation
- Sprint 1B base components
