# Sprint 2.6.2-A/B/C — Preview Focus & Workspace Ergonomics

Version: `1.2.0-rc16`

## Delivered

- Responsive horizontal `QSplitter` for File Panels and Data Preview.
- Default workspace ratio approximately 28/72 with user-adjustable sizing.
- Splitter position persists across application sessions.
- File panel visibility persists across application sessions.
- `Show File Panels` / `Hide File Panels` text and tooltip reflect the current state.
- When File Panels are visible after a workbook is loaded, Workbook Inspector controls are hidden while Data Preview remains visible.
- When File Panels are hidden, Workbook Inspector controls and Data Preview use the available workspace.
- Batch Summary remains live and is rendered as one compact horizontal line.
- Existing semantic colors are preserved for Successful, Failed, Skipped, Invalid and Retried counters.

## Deferred

Virtual Data Grid, live row updates, auto-scroll and per-row status remain scheduled for Sprint 2.6.3/2.6.4.
